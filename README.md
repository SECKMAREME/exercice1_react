# Creation d'un projet react nomme 001 avec vite 
Pour creer ce projet on se place d'abord sur le dossier ou on veut que notre projet soit puis on clique sur la barre de recherche : (code espace point pour pouvoir) l'ouvrir directement sur le vs code puis on fait ctrl+j pour ouvrir le terminal de ce dernier et on tape le code suivant: npm create vite@latest (plus le nom du projet c'est à dire 001) -- --template react
Apres avoir ecrit cette ligne puis entrer il vous pose des questions comme: est ce que vous voulez qu'on le cree si on clique sur entrer ou y ca s'installe directement puis il nous demande est qu'on veut installer avec npm et commencer maintenant on fait le meme procedé finit par nous donner le lien suivant: http://localhost:5173/
c'est le lien qui nous permettra de voir ce que l'on fait c'est à dire l'interface graphique
Toutefois apres avoir ecrit tous ces ligne de commande le projet OO1 se cree et dans le src nous avons l'extension jsx au lieu de js
